Fun facts engineers actually use

DID YOU KNOW?
Session 0 has been non-interactive since Vista specifically to stop shatter-attack-style privilege escalation from services rendering UI on the user's desktop.
DID YOU KNOW?
Ctrl+Alt+Del is the Secure Attention Sequence — it's trapped by the kernel so no user-mode app, including malware, can fake the logon prompt.
DID YOU KNOW?
A Golden Ticket works because the krbtgt account's password never expires by default — its hash signs every TGT in the domain.
